# Security Policy

## Supported versions

Only the latest release on PyPI receives fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through [GitHub security advisories](https://github.com/shuheilocale/japanese-personal-name-dataset/security/advisories/new). You should receive a response within two weeks.

The published package is pure Python with no runtime dependencies and only reads its bundled CSV files. Maintainer-only tools under `.claude/` are not part of the package.
